# kotorime.github.io

Kotori日本語入力の公開文書（プライバシーポリシー、利用規約）を GitHub Pages で公開するリポジトリ。

文面の元データは、それぞれのアプリのリポジトリ（非公開）にある。ここを直接編集せず、元データを直してから写すこと
（アプリに同梱する文面と食い違わないようにするため）。

| 公開先 | 元データ | 写し方 |
|---|---|---|
| `android/` | Android 版のリポジトリの `app/src/main/assets/privacy-policy.md`、`terms-of-service.md` | 2 つのファイルをそのままコピーする |
| `ios/` | iOS 版のリポジトリの `docs/legal/` | iOS 版のリポジトリの `Tools/legal/publish.sh` |
